# ТурВайб

Mobile-first PWA для поиска и сравнения баз отдыха, глэмпингов и отелей.

## Возможности

- выбор дат и состава гостей;
- мгновенная фильтрация доступных объектов по датам, бюджету на весь период и предпочтениям;
- локальная mock-база из 15 вариантов;
- сравнение от 2 до 4 мест по цене, локации, услугам и отзывам;
- базовая PWA-поддержка: manifest и офлайн-кэш локальных ресурсов.

## Запуск

Откройте `index.html` в браузере либо поднимите статический сервер в папке проекта.

## Технологии

Vanilla HTML, CSS и JavaScript. Сервер и внешние API не требуются.
